A newspaper front page that sums up Friday 20 November 2026 in one image. The Trump–Xi–Putin trilateral summit in Shenzhen leads, with the ICJ's genocide ruling against Myanmar, Cyclone Akvan's landfall in Odisha, Iran's strikes on Kuwait and Bahrain, Anthropic's $83 IPO pricing, Voyager 1 reaching one light-day from Earth, and GTA VI's record launch — plus a ticker of the day's other stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to the output directory, unchanged, so both grading runs write identical bytes.

## The image

`entry.png` (1024 × 1024 PNG) was composed for this bounty: the lead illustration was generated for the Shenzhen summit, and the masthead, date line, headlines, story panels and ticker were drawn as crisp vector text so the page stays legible at 300 pixels across. Every story was reported on 20 November 2026.
